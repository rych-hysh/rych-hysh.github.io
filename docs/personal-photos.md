## 写真を追加する

1. 掲載することを確認した画像を `content/photos/` または `content/bike/` に入れます。JPG・PNG・WebP・AVIF に対応し、HEIC は事前に変換します。公開範囲に合わせ、必要なら位置情報などのメタデータを除いたコピーを用意します。
2. `content/photos.yaml` の一覧に `file` と `alt` を記入するか、`content/bike.yaml` の `photos` に画像を追加します。書式は各ファイルのコメントを参照してください。
3. `npm run build` 後にPC・スマホ幅で写真全体の表示と並び順を確認します。タイトルや場所は画面に表示しません。

両フォルダとも、YAML にない画像もファイル名順で自動掲載されます。未確認の素材や下書きは入れないでください。非表示にするときは YAML の項目と画像の両方を取り除きます。

写真がなければトップの写真見出し・ギャラリーは表示しません。バイク写真がなければ写真枠は表示しません。ルートが空なら見出し・バーを表示せず、メーターの隣に愛車情報を表示します。画像を入れると既存のギャラリーが表示されます。

- 一時停止・再生・前後送りを用意。写真上のマウスホバーとキーボードフォーカスでは一時停止し、スワイプ・横ホイール・手動送りの後は再生ボタンを押すまで停止します。縦ホイール操作の既定動作はキャンセルしません。
- 画面外・バックグラウンドでは自動移動を止めます。動きを減らす設定では初期状態を停止にします。JavaScriptがなくても元の写真の横スクロールと一覧ページへのリンクを使えます。

## ボタンなしの一時停止と画像の拡大（2026-10-25）

本人の希望に合わせ、上記の再生・停止・前後送りボタンを削除しました。

- 自分で横スクロール・ドラッグ・タップ・矢印キー操作をすると一時停止。最後の操作や慣性スクロールから8秒後に自動で再開します。マウスを重ねたままでも自動再開します。
- マウスドラッグと画像のクリックを移動量で区別し、ドラッグ後の誤クリックで拡大表示を開きません。スマホではブラウザ標準の縦・横スクロールを利用し、指が触れている間と拡大表示中は自動再開しません。
- ギャラリーは `data-lenis-prevent` でネイティブの横・縦スクロールを使います。ページの縦スクロールと写真の横移動の独立は維持。
- 画像をクリック・タップすると native dialog に高解像度画像を表示。×ボタン・背景・Escで閉じ、元の写真にフォーカスを戻します。写真一覧とバイクの写真も拡大できます。JavaScriptがなければ通常の画像リンクとして開きます。
- ループ用コピーはタップできるよう `inert` を外し、`aria-hidden` と `tabindex=-1` で読み上げとTab移動から除外。閉じるときはコピーではなく元の写真にフォーカスを戻します。
- `main.ts` は拡大表示の開閉時だけLenisを停止・再開し、背景の縦位置を保ちます。
