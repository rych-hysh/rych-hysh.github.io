# ファーストビューの改善

対象ブランチ: `codex/site-first-view`  
ベース: `79d6ead21395f6cb3ddcb666f28079e1f0a4c2a5`

## 今回の変更

- 名前、グラデーション、背景、タイピングを維持し、既存プロフィールを要約した日本語紹介文を追加。
- Hero から「自己紹介・経歴」→ `#about`、「写真・趣味」→ `#hobbies`、「旅の記録」→ `/travel/` に直接移動。
- 固定ナビを「自己紹介 / スキル / 趣味 / 旅の記録 / 連絡先」に変更。スマホはロゴとリンクを2段で表示。
- Hero の紹介文と3導線は、タイピング終了を待たずに表示。肩書きは JavaScript 無効でも HTML に残し、読み上げ用の全文と視覚的な演出を分離。
- ページ内リンクで URL のハッシュとフォーカスを更新。CSS の `scroll-margin-top` を Lenis と標準スクロールの両方に適用。
- Hero とナビの点滅は `prefers-reduced-motion` で停止。

短い紹介文は `content/profile.yaml` の任意項目 `heroIntro` で編集する。未指定時は既存の `intro` を表示する。経歴・写真・旅行先・走行実績のデータは追加していない。

## 他テーマとの接点（未接続）

### 作品セクション

このブランチに `#projects` は存在せず、作品へのリンクや準備中表示は出していない。

統合時は次を確認する。

1. トップページに作品セクションが実際に描画され、`id="projects"` が一意に存在すること。
2. セクションに `.section` を付け、固定ナビを避ける `scroll-margin-top` を適用すること。
3. Hero に「作品を見る」→ `#projects`、ナビに「作品」→ `/#projects` を追加すること。`/#projects` は旅行ページからトップへの移動にも使える。
4. 作品導線の追加時に主ボタンを作品に変更するか確認すること。現状の主ボタンは自己紹介。
5. 6項目になるスマホナビは、この5項目配置にそのまま足さず、折り返しなどを再設計して320px幅でも確認すること。高さを変える場合は `scroll-margin-top` と Hero の上余白も見直すこと。

### 写真・旅行・バイク

- 現在の写真導線は既存の `#hobbies`。写真専用ページや `#photos` の存在は前提にしていない。
- `/travel/` は既存ページへの導線。旅行機能自体の変更は含めない。
- 趣味側でアンカーや URL を変更する場合は、Hero・Nav の該当リンクを合わせて更新する。
- `src/scripts/main.ts` は他テーマも変更し得る共有ファイル。統合ではアンカー処理・肩書きの初期化だけを適用し、他のアニメーション変更を上書きしない。

## ローカル確認

Node.js 24.22.1、lockfile 固定の `npm ci` で確認。OS 標準の Node.js 20.13.0 は、現在の依存関係の要求より古いため使用していない。

確認結果:

- Astro の本番ビルド成功。`astro check` は22ファイルでエラー・警告・ヒント各0件。
- トップと `/travel/` が HTTP 200。生成 HTML 内のページ内リンク先はすべて存在し、ID の重複や `#projects` へのリンクなし。
- ブラウザーで320×568、390×844、768×1024、1280×720を確認。横方向のページはみ出しなし。320×568でも Hero の3リンクが画面内に収まる。
- Hero の自己紹介・趣味リンク、Enter キー、URL のハッシュ更新、移動後のフォーカス、固定ナビの下への配置を確認。スマホの移動先の上端は約128px、ナビ下端は約119px。
- ナビから旅行ページへ移動し、「旅の記録」の `aria-current="page"` と、旅行ページから `/#about` に戻る動作を確認。
- 確認中のブラウザーコンソールにエラー・警告なし。
- JavaScript 無効時の肩書き・リンクは生成 HTML で確認。JavaScript 無効・reduced-motion 設定でのブラウザー表示は未確認。
