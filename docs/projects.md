## 作品を差し替える

`content/projects.yaml` の配列を編集します。順番がそのまま表示順です。

```yaml
- id: your-app
  published: true
  sample: false
  name: 確認済みのアプリ名
  summary: 何のためのアプリか、誰のどんな課題を解決するか
  role: 本人が担当した範囲
  features:
    - 具体的な特徴
  status: 公開状況（任意、本人に確認した文言）
  stack: [TypeScript] # 任意
  links: # 任意。http / https の URL のみ
    - label: 紹介サイトを見る
      url: https://example.com/
  screenshot: # 任意。画像がなければこの項目全体を省略
    file: your-app.png
    alt: 画面から分かる操作や情報
    caption: 画面についての補足（任意）
```

- 必須項目は `id`・`name`・`summary`・`role`・1件以上の `features`。
- `id` は小文字の半角英数字とハイフンで重複しない値にします。
- `published` を省略するか `false` にするとカードは表示されません。
- 空配列 `[]` または掲載対象0件なら、`#projects` セクション全体を出力しません。
- `sample: true` は「架空のアプリ」と表示します。実際の情報を確認して差し替えたら `false` にします。
- 未公開情報・未承認の画像・秘密情報はリポジトリに置かないでください。`published: false` は表示制御であり、リポジトリやビルド成果物のアクセス制御ではありません。
- 画像は `content/projects/` に追加します。PNG / JPEG / WebP / AVIF に対応。ファイル名の大文字小文字は一致させます。
- 画像は縦長・横長とも全体を収めて表示し、遅延読み込みと Astro の画像最適化を使います。未指定なら文章のみのカードです。
- スマートフォンでは作品名・概要・公開リンクを先に表示し、担当・特徴・使用技術は「担当・特徴を詳しく見る」で開閉できます。画像は全体を収めた最大高128pxのプレビューです。PCでは詳細を常時表示します。
- JavaScriptが無効な場合も、詳細は初期状態で開き、すべての内容を読めます。サンプル画像の編集元は `docs/samples/reading-log.svg` です。
- 実際の作品・画面・担当・使用技術・公開リンク・掲載可否は、差し替え前に本人に確認してください。
